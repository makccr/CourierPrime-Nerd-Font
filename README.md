# Courier Prime Nerd Font
A version of [Courier Prime](http://quoteunquoteapps.com/courierprime) & [Courier Prime Code](https://github.com/quoteunquoteapps/CourierPrimeCode), patched to include [Nerd Font](https://www.nerdfonts.com/) glyphs.

<p align="center"><img src="https://raw.githubusercontent.com/makccr/CourierPrime-Nerd-Font/refs/heads/master/releases/sample.png"></p>

## Download & Installation
Download the latest by cloning this repository, or downloadng the [latest release](https://github.com/makccr/CourierPrime-Nerd-Font/releases/). 

### Linux
Move the full font directory into either `~/.fonts` or `/usr/share/fonts`.

### MacOS or Windows
Click the font file and let your OS magically do all the fun stuff for you.
